## 한 줄 정의

이 역할이 없으면 **로컬에서만 돌아가는 데모**로 끝납니다. 과제 요구사항의 절반(배포·운영)이 이 역할입니다.

## 소유 경로

`CODEOWNERS`와 **같은 경로**여야 합니다. 다르면 리뷰 자동 배정이 엉뚱한 사람에게 갑니다.

- `apps/backend/`
- `infra/`

## 책임

- 생성 잡의 수명주기(접수 → 진행 → 완료/실패)를 관리한다. **동기 HTTP로 붙들지 않는다**
- ai-engine 장애 시 폴백으로 전환하고 그 사실을 응답에 드러낸다
- GCP VM을 프로비저닝하고 compose 스택을 상시 기동 상태로 만든다
- 재부팅 후 자동 복구를 **실제로 재부팅해서** 확인한다
- 생성 지연·실패율·폴백률을 사후 조회 가능하게 남긴다
- GPU 시간 분할 규칙(학습 vs 추론)과 비용 알림(예산 임계값)을 설정한다

## 하지 않는 일 (경계)

책임보다 이 항목이 분쟁을 더 많이 막습니다.

- 프롬프트 조립·모델 호출 (03 소관). backend는 GPU를 점유하지 않습니다
- 계약 변경 (02와 합의 후 `openapi.yaml`이 먼저)
- 시크릿 값을 저장소에 넣는 일 — `infra/.env.example`에는 **키 이름만**

## 산출물

| 산출물 | 위치 | 완료 판단 기준 |
|---|---|---|
| 비동기 잡 경로 | `apps/backend/src/` | 잡 접수 응답이 즉시 반환되고 상태 조회로 결과 수신 |
| 배포된 서비스 | GCP VM | 외부에서 접근 가능 + 재부팅 1회 실검증 통과 |
| 운영 관측 | `infra/` | 지연 p95·실패율·폴백률을 사후에 조회 가능 |
| 비용 가드 | GCP 콘솔 | 예산 임계값 알림 설정 완료 |

## 인수인계 시 넘겨야 하는 것

이 역할이 빠졌을 때 다음 사람이 곧바로 이어받으려면 무엇이 문서로 남아 있어야 하는가.
**"머릿속에만 있는 것"을 여기에 적고, 그것을 없애는 것**이 이 항목의 목적입니다.

- VM에만 있는 설정 (방화벽 규칙, 서비스 계정 권한, 부팅 스크립트) — 저장소에 없는 것 전부
- 시크릿의 **보관 위치**(값이 아니라 위치)와 재발급 절차
- 장애 시 확인 순서 (무엇부터 보는가)
