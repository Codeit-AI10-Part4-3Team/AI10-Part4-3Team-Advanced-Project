# 2026-08-19_소관배정_화풍확정_카피경로확인

## 배경

2026-08-18 회의(이미지 생성 경로 결정)에서 A-1, A-2 방향은 정해졌으나 구현 소관 4건이
배정되지 않은 채 남았습니다. 오늘 회의는 그 소관을 배정하고, 화풍 후보 8종(A-3)을 확정하며,
카피 경로(기획서 13.2)가 여전히 유효한지 확인합니다.


## 1. 소관 배정 4건

**확인된 것**: 08-18 회의록이 담당자를 비워 둔 항목이 4건입니다 - 컷별 생성 구현(A-2),
병렬 호출과 부분 실패 처리(항목 5), 품질 티어의 출력 유형별 분리 적용, 대사 상한 추가 시험
(A-1 후속). 넷 다 `image:render` 이음매 실물화(03 일정, 08-22 ~ 08-26)에 직결됩니다.

**결정**:

| 항목 | 소관 | 비고 |
|---|---|---|
| 컷별 생성 구현 (프롬프트 6장 생성 + 3x2 합성) | **03 (신호정)** | A-2 결정의 구현. `image:render` 실물화에 포함 |
| 병렬 호출과 부분 실패 처리 | **03 (신호정)** | ai-engine 내부에서 5건 동시 호출과 실패 처리를 담당. 잡 단위 동시 실행 수 상한은 아래 참고 |
| 잡 단위 동시 실행 수 상한 / 큐 처리 | **05 (임동규)** | `render_timeout_s`와 잡 워커가 `backend_core` 소유이므로 분리. 신호정 제안(큐 처리 우선 검토, 08-18 회의록)을 이어받음 |
| 품질 티어의 출력 유형별 분리 적용 | **03 (신호정)** | `ADGEN_IMAGE_QUALITY`를 만화형/단일광고형별로 다르게 적용 가능한지 확인 포함 |
| 대사 상한 추가 시험 (15 ~ 20자 표본) | **03 (신호정)** | A-1 후속. 상한 수치가 나오면 미결정_대장 A-1 갱신 |

**후속 필요**: 병렬/실패 처리는 ai-engine(03)과 backend(05) 양쪽에 걸치므로, 아키텍처 경계
(`apps/ai-engine` 와 `apps/backend` 는 계약으로만 결합)를 넘지 않도록 두 담당이 인터페이스를
먼저 맞춥니다.

## 2. 화풍 후보 8종 확정 + 검증 5순위 판정 명단

**확인된 것**: 미결정_대장 A-3은 여전히 잠정 상태입니다. 8종이라는 숫자의 근거는 기획서
12.2의 4x2 화면 격자뿐이며, 실제 후보 목록은 이전 회의에서 확정된 적이 없습니다. 검증 5순위
판정자는 B-15에서 이미 "AI 담당 제외 전원"으로 확정되어 있습니다.

**결정**:

- 화풍 후보 8종

| 화풍 | 특징 | 잘 맞는 광고 |
|---|---|---|
| 심플 플랫 웹툰 | 굵은 선, 단순한 색, 풍부한 표정 | 앱, 플랫폼, 생활 서비스 |
| 한국형 일상 웹툰 | 친근한 인물과 현실적인 공감 상황 | 식품, 배달, 금융, 교육 |
| SD 캐릭터, 치비 | 큰 머리와 과장된 리액션, 귀여운 인상 | 캐릭터 상품, 게임, 젊은 타깃 |
| 레트로 팝아트 | 강한 원색, 망점, 광고 포스터 같은 연출 | 패션, 음료, 이벤트 |
| 감성 수채화 | 부드러운 색과 손으로 그린 듯한 질감 | 여행, 카페, 뷰티, 친환경 제품 |
| 세련된 에디토리얼 | 절제된 선과 색, 잡지 일러스트 분위기 | 프리미엄 브랜드, 금융, B2B |
| 3D 클레이 캐릭터 | 말랑하고 입체적인 캐릭터, 높은 주목도 | IT 서비스, 키즈, 프로모션 |
| 시네마틱 애니메이션 | 극적인 구도와 조명, 이야기 몰입도가 높음 | 자동차, 게임, 브랜드 캠페인 |

- 검증 5순위 판정 명단: **정승호, 임동규, 송기하** (B-15 재확인, AI 담당인 신호정 제외)

**후속 필요**: 화풍 후보 8종 목록이 확정되는 대로 미결정_대장 A-3의 등급을 `차단`에서
`확정`으로 바꾸고 이 회의록을 근거로 링크합니다. 목록 자체는
[03-AI_생성_서빙.md](../역할_일정/03-AI_생성_서빙.md)의 "화풍 후보 8종과 예시 이미지" 항목에
기록합니다.

## 3. 카피 경로 - 기획서 13.2 유지 확인

**확인된 것**: 기획서 13.2의 기준 구성은 "텍스트와 이미지 모두 GPT API"입니다. 08-18
회의는 이미지 생성 경로(로컬 모델 병행 검토)만 다루었고 텍스트/카피 경로는 다루지 않았습니다.
그 사이 카피 경로를 바꾸자는 제안이나 근거 문서 변경이 없었습니다.

**결정**: 새로 결정하지 않습니다. 기획서 13.2를 그대로 유지합니다. 카피는 계속 GPT API로
생성합니다.
