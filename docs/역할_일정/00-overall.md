## 크리티컬 패스 (여기가 밀리면 전체가 밀립니다)

붉은 경로가 **가장 긴 사슬**입니다. 여기 있는 작업이 하루 밀리면 제출일이 하루 밀립니다.

```mermaid
flowchart LR
    FREEZE["계약 동결<br/>08-08"]
    PARA["프론트 · 백엔드 · AI<br/>병렬 구현"]
    MODEL["base 모델 확정<br/>08-08"]
    DATA["데이터 준비 + 권리 확인"]
    TRAIN["학습 1회전<br/>~08-17"]
    INFER["어댑터 적용 추론<br/>~08-22"]
    DEPLOY["배포<br/>08-24"]
    MEASURE["지표 실측<br/>~08-29"]
    SUBMIT(["제출<br/>08-31"])
    QUOTA["GPU quota 신청<br/>W1"]
    VMTEST["VM 빈 스택 1회 배포<br/>W2"]

    FREEZE --> PARA --> DEPLOY
    MODEL --> DATA --> TRAIN --> INFER --> DEPLOY --> MEASURE --> SUBMIT
    QUOTA --> VMTEST --> DEPLOY

    classDef crit fill:#fde2e2,stroke:#c0392b,stroke-width:2px
    class MODEL,DATA,TRAIN,INFER,DEPLOY,MEASURE,SUBMIT crit
```

- **계약 동결이 하루 밀리면 4명이 하루씩 대기합니다.** 미정 필드는 optional로 열어 두고
  일단 동결하는 편이 낫습니다.
- **학습은 되돌리기가 가장 느린 작업**입니다(데이터 → 학습 → 평가가 각각 시간 단위).
  W2에 1회전을 반드시 시작하세요. W3 시작으로 미루면 재시도 기회가 없습니다.
- **배포를 마지막 주로 미루지 마세요.** W2에 빈 껍데기라도 VM에 한 번 올려 두면
  "우리 환경에서만 안 되는 것"을 미리 발견합니다. 마지막 주에 처음 올리면 그것이 곧 사고입니다.
