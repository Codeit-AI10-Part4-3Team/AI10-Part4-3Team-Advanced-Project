# 역할 일정

**언제까지 무엇이 끝나야 하는지**를 역할별로 정리하는 곳입니다. 누가 무엇을 하는지는
[역할_가이드/](../역할_가이드/README.md)에 있습니다.

## 규칙

- 파일명은 `NN-역할명.md`. `역할_가이드/`와 **같은 번호** — 1:1 대응입니다.
- 전체 일정은 [00-overall.md](00-overall.md)가 원천이고, 개별 파일은 그 안의 자기 몫을 자세히 씁니다.
  전체 일정과 개인 일정이 어긋나면 **00-overall이 맞습니다**.
- **날짜는 절대 표기**로 씁니다(`2026-08-10`). "다음 주"는 나중에 읽을 수 없습니다.
- 각 작업에는 **완료 조건(DoD)**을 적으세요. "구현한다"는 완료 조건이 아닙니다.
