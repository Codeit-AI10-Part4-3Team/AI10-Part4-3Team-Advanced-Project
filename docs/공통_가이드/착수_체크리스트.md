## 앱/폴더를 추가할 때 (상시 규칙)

체크리스트가 아니라 **규칙**입니다. 어기면 모든 PR이 조용히 막힙니다.

| 고칠 곳 | 빠뜨리면 |
|---|---|
| 루트 `pyproject.toml`의 ruff `src` | isort가 앱 내부 import를 서드파티로 보고 CI가 I001로 실패 |
| `.github/workflows/ci.yml`의 matrix | 새 앱이 검사되지 않음 |
| `scripts/setup-github.sh`의 `contexts` | required check 이름 불일치 → 머지가 영원히 `Expected` 대기 |
