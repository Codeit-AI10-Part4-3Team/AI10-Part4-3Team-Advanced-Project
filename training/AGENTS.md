# training — 디렉토리 규칙

루트 [/AGENTS.md](../AGENTS.md)가 전역 정본, 파이프라인 상세는 이 폴더의 [README.md](README.md).

- **`apps/`와 서로 import하지 않습니다(양방향 금지).** 서빙과 만나는 유일한 지점은 **파일**:
  어댑터 가중치 + `adapter_card.json`. 이 선이 있어야 학습 코드가 깨져도 서비스는 base 모델로 뜨고,
  서비스 리팩터링이 학습 재현성을 건드리지 않습니다
  ([ADR-0002](../docs/adr/0002-학습_파이프라인_배치.md)).
- **`data/`는 커밋 금지, README(권리 대장)만 추적.** 대장에 기록되지 않은 데이터로 학습한 모델은
  배포 판단을 내릴 수 없습니다. `runs/`(산출물·로그)도 커밋 금지.
- **`configs/`는 커밋 대상** — 재현의 단일 원천입니다.
- **GPU는 배포된 서비스와 공유합니다.** 학습은 운영 시간 외에 돌리거나 VRAM 예산을 명시적으로
  분할하세요 — "일단 돌려보자"는 서비스 다운으로 직결됩니다.
- ruff는 적용되지만 **CI 매트릭스에는 없습니다** — "린트 계약"은 [README.md](README.md) 참고.
