## 한 줄 정의

이 역할이 없으면 **생성 자체가 없습니다**. 카피와 이미지를 실제로 만들어 내고, 지어내지 않도록 막는 사람입니다.

## 소유 경로

`CODEOWNERS`와 **같은 경로**여야 합니다. 다르면 리뷰 자동 배정이 엉뚱한 사람에게 갑니다.

- `apps/ai-engine/` (`eval/` 제외 — 채점은 07과 공동 소유)

## 책임

- [기획서](../기획서/기획서.md) 15절의 **검증 실험을 수행하고 결과를 보고한다** — 이미지 생성
  경로(ADR `0003`)와 컷 경계 제어 방법이 이 결과에 달려 있습니다
- 카피 생성기를 스텁에서 실물로 교체한다 (`ai_engine.generation.Generator` 이음매)
- 이미지 생성 경로를 만든다 — **기준 구성은 외부 API이며**, 로컬 모델과 LoRA 어댑터 로딩은
  ADR `0003`이 그렇게 결정할 때 켜집니다. 04가 어댑터를 넘기는 경로는 **되살릴 때** 쓰는 것이지
  기본 경로가 아닙니다
- **차단 항목에 걸리는 코드는 그것이 정해지기 전에 쓰지 않는다** — 이 역할에 걸린 것은 컷 경계
  제어 방법(A-2)과 화풍 후보 목록(A-3, 송기하와 공동)입니다. 등급과 현재 상태의 정본은
  [미결정_대장.md](../기술문서/미결정_대장.md) 한 곳입니다
- 이음매의 더미 구현은 02가 만듭니다. 실물은 **그 분기의 한쪽을 채우는 형태**로 들어오므로
  호출부와 계약을 건드리지 않는다 ([구현_범위.md](../공통_가이드/구현_범위.md) 1.1절)
- 가드레일을 2단(프롬프트 제약 + **출력 검증**)으로 유지하고 on/off 대조 실행을 가능하게 둔다
- 가드레일이 거절하면 **같은 부분을 1회만 재생성**하고, 재차 위반하면 `CONTENT_POLICY_REJECTED`로
  돌려준다. 위반한 문구를 다듬어 내보내는 경로는 만들지 않는다
  ([ADR-0005](../adr/0005-열화_폴백은_자동화_생략으로_한정.md))
- 생성 지연을 줄이는 작업(해상도·스텝·스케줄러)을 지표와 함께 보고한다

## 하지 않는 일 (경계)

책임보다 이 항목이 분쟁을 더 많이 막습니다.

- 학습 (04 소관). 어댑터는 **파일로 받습니다** — `training/`을 import하지 않습니다
- 잡 상태 관리·인증 (05 소관). ai-engine은 상태를 갖지 않습니다
- 자기 출력의 채점 기준 결정 (07과 공동, 자기채점 편향 배제)

## 산출물

| 산출물 | 위치 | 완료 판단 기준 |
|---|---|---|
| 실물 카피 생성 | `apps/ai-engine/src/ai_engine/generation.py` | 스텁 클래스가 사라지고 계약 준수 테스트 통과 |
| 이미지 생성 경로 | `apps/ai-engine/src/ai_engine/` | 같은 프롬프트에서 base 대비 브랜드 톤 차이가 눈으로 구분됨 |
| 가드레일 대조 실행 | `ai_engine.guardrail` | on/off 델타가 `eval/` 출력에 숫자로 나옴 |
| 실패 경로 | - | 모델을 못 쓰는 상태에서 503 `UPSTREAM_UNAVAILABLE`. **200에 지어낸 카피가 실리지 않음** |

## 인수인계 시 넘겨야 하는 것

이 역할이 빠졌을 때 다음 사람이 곧바로 이어받으려면 무엇이 문서로 남아 있어야 하는가.
**"머릿속에만 있는 것"을 여기에 적고, 그것을 없애는 것**이 이 항목의 목적입니다.

- 프롬프트 템플릿의 각 문장이 왜 그렇게 쓰였는지 (지운 순간 품질이 떨어지는 줄이 있습니다)
- 시도했다가 버린 접근과 그 이유
- 모델 호출의 타임아웃·재시도 값이 그 숫자인 근거
