두 실측 보고서를 나란히 놓은 문서입니다. 새 실험은 없으며, 아래 두 보고서의 수치만 인용합니다.

| [로컬모델_탐색_보고서.md](로컬모델_탐색_보고서.md) | FLUX, SDXL, Qwen-Image | 2026-08-15 |

**이 문서는 결정도 권고도 아닙니다.** 미결정 대장 A-5(로컬 모델 채택 여부)의 확정 근거는 검증
4순위 결과이고, 그 과제의 판정자는 임동규, 송기하 2명이며 두 사람 모두 동의해야 통과합니다
(B-15). 두 보고서 모두 수행자가 같은 사람이므로, 이 문서가 채택을 주장하면 기획서 15절의
자기 채점 금지에 걸립니다. 여기서는 **무엇이 갈리는지만** 정리합니다.

## A. 한눈에 보는 비교

| 축 | 외부 API (`gpt-image-2`) | 로컬 (SDXL + 레퍼런스 2장 + 합성) |
|---|---|---|
| 한국어 카피 | **정확.** 판정자 3명 전원 100퍼센트, 120칸 오탈자 0건 | 모델은 못 그림. **합성으로 우리가 그리므로 구성상 보장** |
| 긴 문장 | 30자에서 첫 오탈자 발생 | 길이 제약 없음 (합성) |
| 화풍 통제 | **프롬프트뿐이고 잘 듣지 않음.** 같은 지시문에 실사와 일러스트가 섞임 | **IP-Adapter로 6종 전이 6/6** |
| 제품 동일성 | 입력 사진 5회 모두 보존 | 글자 없음 30/30. **제품 충실도는 미측정** |
| 장당 시간 | 20.3초 (단일 광고형) | **15.2초** + 합성 1초 미만 |
| 만화 6칸 | 54 ~ 122초 (한 장) / **55.9 ~ 139.2초 (컷별 병렬)** | 6칸 기준 미측정 |
| 장당 비용 | 0.0069 USD (단일 광고형) | 전기값 외 0 |
| 규격 정합 | 한 장 생성은 **칸 1101 ~ 1142px로 흔들림** | 해당 없음 (칸을 우리가 붙임) |
| 필요 자원 | API 키, 네트워크 | **VRAM 12.91GB, 디스크 10GB, GPU 점유** |
| 추가 단계 | 없음 | **한국어에서 영어로 번역**, 후처리 합성 |
| 라이선스 | 벤더 약관 | CreativeML Open RAIL++-M (SDXL) |

## B. 두 경로의 강약점이 정확히 어긋납니다

### B-a. 한국어는 API가, 화풍 적용은 로컬이 앞섭니다

이 비교의 핵심입니다. 한쪽이 못 하는 것을 다른 쪽이 합니다.

**한국어 카피**에서 로컬은 세 후보 모두 실패했습니다. FLUX는 한국어 프롬프트를 이해하지 못해
주제와 무관한 이미지를 냈고 글자 없음이 0/10입니다. Qwen-Image는 한글 글자꼴을 그리지만 철자가
0/5이고 장당 215초입니다. SDXL은 애초에 한글을 그리지 못합니다. 반면 외부 API는 짧은 대사
120칸에서 오탈자가 하나도 없었습니다.

**화풍 통제**에서는 반대입니다. 외부 API는 "깔끔한 한국 웹툰 스타일"이라는 같은 지시문을 주었는데
회차 묶음마다 실사와 일러스트로 갈렸습니다. 통제 수단이 프롬프트 문구뿐이라 재현되지 않습니다.
로컬은 IP-Adapter로 레퍼런스 이미지를 직접 주므로 화풍 6종이 6/6으로 전이되고 시드가 달라도
유지됩니다.

브랜드 스타일 광고 소재가 이 프로젝트의 목적이므로, **화풍의 재현성은 부가 기능이 아니라 제품의
본체**입니다. 동시에 카피가 틀린 광고는 쓸 수 없습니다. 두 조건이 서로 다른 경로에 걸려 있는
것이 현재 상황입니다.

### B-b. 두 경로가 같은 해법으로 수렴합니다

두 보고서가 독립적으로 **후처리 합성**에 도달했습니다. 다만 이유가 다릅니다.

| | 왜 합성으로 갔는가 | 합성이 없으면 |
|---|---|---|
| 로컬 | 모델이 한글을 못 그립니다 | 경로 자체가 성립하지 않습니다 |
| 외부 API | 칸 크기와 여백이 회차마다 흔들립니다 | 고정 좌표 크롭이 불가능합니다 |

외부 API 쪽에서는 컷을 하나씩 만들어 우리가 붙이자 칸이 정확히 1152 x 1152가 되고 바깥 여백이
0이 되었습니다. 로컬 쪽에서는 글자 없는 제품컷을 만든 뒤 카피를 Pillow로 얹어 철자를 구성상
보장했습니다.

**즉 어느 경로를 택하든 합성 단계가 파이프라인에 들어옵니다.** 이것은 두 보고서를 함께 읽어야
보이는 사실이며, 미결정 대장 A-1(대사 렌더링 방식)의 예비안이 어느 쪽에서도 유리해진다는 뜻입니다.

### B-c. 제품 동일성은 서로 다른 것을 쟀습니다

두 보고서의 숫자를 직접 비교하면 안 됩니다.

| | 무엇을 쟀는가 | 결과 |
|---|---|---|
| 외부 API | 입력한 실제 제품 사진이 결과에 보존되는가 | 5회 모두 보존 (로고, 한글 표기, 용량 표기까지) |
| 로컬 | 제품 라벨에 가짜 글자가 없는가 | 30/30 |

로컬 보고서는 **제품 충실도 축을 이번 회차에서 재지 않았다**고 명시합니다. 오히려 장면
레퍼런스의 내용물이 제품 안으로 새어 봉투가 조약돌로 채워지는 사례를 보고했습니다. 따라서
"제품이 유지되는가"에 대해 지금 답이 있는 것은 외부 API뿐입니다.

## C. 비용 축은 출력 유형에 따라 갈립니다

두 보고서의 초고가 여기서 어긋났습니다. 로컬 보고서 9절이 비용은 판단 축에서 빠진다고 유형 구분
없이 적었기 때문입니다. 단일 광고형 장당 0.0069 USD이고 결제 계정이 학원 소유라는 근거였습니다.

**그러나 외부 API에는 30 USD 상한이 있습니다.** 학원 크레딧은 VM에 대한 것이고 API 예산은 별개로
확인된 값입니다. 이 상한으로 환산하면 아래와 같습니다.

| 생성 방식 | 장당 | 30 USD로 만들 수 있는 양 |
|---|---|---|
| 단일 광고형 | 0.0069 USD | 약 4,300장 |
| 제품 사진 입력 | 0.0271 USD | 약 1,100장 |
| 만화형 한 장 | 0.1171 USD | 약 250장 |
| 만화형 컷별 `low` | 0.0974 USD | 약 300세트 |
| 만화형 컷별 `medium` | 0.4041 USD | 약 74세트 |

**단일 광고형만 보면 비용은 실제로 판단 축이 아닙니다.** 4,300장은 개발과 시연에 충분합니다.
그러나 **만화형을 `medium` 이상으로 돌리면 74세트가 상한**이고, 이미 90회에 6.06 USD를 썼습니다.
남은 예산은 약 24 USD입니다.

따라서 정확한 서술은 이렇습니다. 비용은 단일 광고형에서는 판단 축이 아니고, **만화형에서는 품질
티어에 따라 판단 축이 됩니다.** 로컬 경로는 이 제약을 받지 않습니다.

**두 보고서를 이 서술로 통일했습니다** (2026-08-18 회의 4번 결정). 로컬 보고서 9절도 같은 표를
싣고 있으므로, 어느 쪽을 먼저 읽어도 같은 결론에 닿습니다.

## D. 운영 부담

로컬 경로를 택하면 새로 생기는 것들입니다. 외부 API에는 없습니다.

| 항목 | 내용 |
|---|---|
| GPU 점유 | VM에 GPU가 한 대뿐입니다. 추론이 VRAM을 쥐고 있으면 학습과 배포가 함께 죽습니다. 시간 분할 합의가 선행 조건이며 아직 합의되지 않았습니다 |
| 번역 단계 | 로컬 모델은 한국어 프롬프트를 이해하지 못합니다. 프롬프트 조립 단계에 한국어에서 영어로의 번역이 들어가고, **번역 품질이 곧 이미지 품질**이 됩니다. 지금 파이프라인 설계에 없는 단계입니다 |
| 디스크 | 후보를 동시에 둘 수 없습니다. FLUX와 Qwen을 함께 받지 못해 하나를 지우고 받았습니다 |
| 라이선스 | SDXL은 CreativeML Open RAIL++-M입니다. 상업적 사용 조건을 확인해야 하며 ADR로 남길 사안입니다 |
| 모델 준비 | 가중치 다운로드와 환경 구성이 배포 절차에 들어옵니다 |

반대로 외부 API에만 있는 부담입니다.

| 항목 | 내용 |
|---|---|
| 예산 상한 | 30 USD. 만화형 고티어에서 실질 제약이 됩니다 |
| 품질 티어 흔들림 | `quality`를 지정하지 않으면 같은 요청이 최대 9배까지 비싸집니다 |
| 키 관리 | 저장소가 public이므로 유출 시 폐기와 재발급입니다 |
| 네트워크 의존 | 시연 중 외부 장애가 곧 서비스 중단입니다 |

## E. 검증 4순위가 물어야 할 것

두 탐색으로 질문이 좁혀졌습니다. 로컬 보고서가 정리한 물음을 그대로 옮깁니다.

> IP-Adapter로 얻는 브랜드 톤 통제가, 한국어 카피를 후처리 합성으로 옮기는 비용을 감당할
> 만한가.

여기에 이 비교로 추가되는 물음이 둘입니다.

1. **합성이 어느 쪽에서도 필요하다면, 그 자체는 더 이상 로컬 경로의 대가가 아닙니다.** 외부 API도
   규격 정합을 위해 컷별 생성과 합성으로 가는 것이 유리했습니다. 그렇다면 남는 차이는 화풍 통제
   수단과 번역 단계뿐입니다.
2. **제품 충실도를 로컬에서 아직 재지 않았습니다.** 외부 API는 5/5로 보존했습니다. 4순위에서 이
   축을 같은 기준으로 재지 않으면 비교가 성립하지 않습니다.

### E-a. 4순위 실행 전에 갖춰야 할 것

| 항목 | 현재 상태 |
|---|---|
| 비교 조건 고정 (프롬프트, 해상도, 시도 횟수) | 미착수. 08-18 ~ 19 예정 |
| 제품 충실도 판정 기준 | 없음. 두 경로에 같은 기준을 적용해야 합니다 |
| 화풍 전이 판정 기준 | 없음. 사람 평가와의 상관 확인 전에는 대리 지표를 쓸 수 없습니다 |
| GPU 시간 분할 합의 | 미합의 |
| 판정자 확보 | 임동규, 송기하 2명. 두 사람 모두 동의해야 통과 (B-15) |

## F. 공백

두 보고서를 합쳐도 답이 없는 항목입니다.

| 항목 | 왜 비어 있는가 |
|---|---|
| 로컬의 만화 6칸 | 로컬 탐색은 단일 광고형만 쟀습니다. 6칸 조건의 시간과 VRAM은 미측정입니다 |
| 로컬의 제품 충실도 | 로컬 보고서가 재지 않았다고 명시합니다 |
| 화풍 지표 | 양쪽 모두 육안입니다. 기계 판정 지표가 없습니다 |
| 세션당 단가 | 카피 생성 경로가 미확정이라 텍스트 호출을 어느 쪽에서도 재지 못했습니다 |
| 검증 5순위 화풍 반영 | 화풍 후보 목록(A-3)이 미확정이라 양쪽 모두 착수 불가입니다 |
| 표본 크기 | 로컬은 조건당 5장으로 판정 회차의 20회 기준에 못 미칩니다 |

## G. 요약

- 두 경로는 **강약점이 서로 어긋납니다.** 한국어는 API가, 화풍 통제는 로컬이 앞섭니다.
- 두 경로 모두 **후처리 합성으로 수렴**합니다. 이유는 다르지만 결과가 같습니다.
- 비용은 **단일 광고형에서는 판단 축이 아니고 만화형 고티어에서는 판단 축**입니다.
- 로컬을 택하면 **번역 단계와 GPU 시간 분할**이 새로 생깁니다.
- **제품 충실도는 아직 같은 기준으로 재지 않았습니다.** 4순위의 선결 과제입니다.

확정은 회의록으로 합니다.
