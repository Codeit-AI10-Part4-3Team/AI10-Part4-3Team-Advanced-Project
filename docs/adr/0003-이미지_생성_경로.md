# ADR-0003: 이미지 생성은 당분간 외부 API만 쓰고, 로컬 모델은 검증 4순위 결과로 판단합니다

- **상태**: Accepted
- **날짜**: 2026-08-13
- **결정자**: 임유빈 (03 AI 생성/서빙) 판단, 2026-08-11 회의에서 팀 확정
- **관련**: [ADR-0004](0004-파인튜닝_보류.md), [ADR-0011](0011-배포_환경_스펙과_권한_경계.md),
  [2026-08-11 회의록](../회의록/2026-08-11_차단7건_회의결정.md) A절 1번, 3번,
  **[2026-08-20 회의록](../회의록/2026-08-20_검증4순위_로컬모델_미채택.md)** (이 ADR 이 예약한
  재검토 시점이 발화한 자리입니다),
  [미결정_대장.md](../기술문서/미결정_대장.md) A-5, E절,
  [구현_범위.md](../공통_가이드/구현_범위.md) 4.1절

## 배경

[AGENTS.md](../../AGENTS.md)가 base 이미지 생성 모델 선택을 TBD로 두고 "라이선스가 함께 걸리므로
ADR로 남길 것"을 지시하고 있었습니다. 이 항목이 열려 있는 동안에는 생성 경로에 붙는 코드를 쓸 수
없고, 실제로 워킹 스켈레톤의 `image:render` 이음매가 스텁으로만 존재하는 이유가 이것입니다.

결정을 어렵게 만든 것은 세 가지가 한 선택에 묶여 있다는 점입니다.

- **하드웨어 예산이 좁습니다.** 가용 VRAM 22.5GB, 호스트 RAM 16GB, 디스크 100GB이며 상향은
  협상 대상이 아닙니다 ([ADR-0011](0011-배포_환경_스펙과_권한_경계.md)). GPU는 한 대뿐이라
  학습과 추론이 동시에 VRAM을 요구하면 둘 다 실패합니다.
- **라이선스는 되돌리는 비용이 큽니다.** 상업적 이용과 파인튜닝 허용 여부를 원문으로 확인하지
  않은 채 진행하면, 뒤집혔을 때 22일 일정을 직격합니다 ([리스크.md](../공통_가이드/리스크.md) 3번).
- **품질을 아직 모릅니다.** 이 서비스의 성패는 6칸 만화에 한국어 대사가 정확히 그려지는지에
  달려 있는데(검증 1순위), 그 답이 나오기 전에 모델을 고르면 근거 없는 선택이 됩니다.

일정도 제약입니다. 실작업 22일 중 이미 9일이 지났고, 워킹 스켈레톤 관통의 실질 마감이
2026-08-14입니다. 모델 선정을 기다리는 동안 멈추는 사람이 생기면 그 손실은 회수되지 않습니다.

## 검토한 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. **외부 API(GPT 계열 이미지 API)만 쓰고, 로컬 모델 채택은 검증 4순위 결과로 판단한다** | 개발 속도가 하드웨어와 무관해집니다. VRAM 예산과 GPU 1대 제약이 생성 경로에서 사라집니다. 라이선스 확인 부담이 서비스 약관 하나로 줄어듭니다 | 세션당 비용이 호출량에 비례합니다. 모델 교체와 파라미터 통제 범위가 제공자에게 종속됩니다 |
| B. 로컬 모델(SDXL/FLUX 등)을 지금 고르고 VM에 올린다 | 비용이 고정됩니다. 파인튜닝과 IP-Adapter 같은 통제 수단이 열립니다 | 22.5GB 안에 들어가는지, 한국어 대사를 그릴 수 있는지 **아직 아무도 모릅니다**. 라이선스 원문 확인이 선행되어야 합니다. 모델 선정에 며칠이 들어가고 그 며칠이 스켈레톤 관통과 겹칩니다 |
| C. 둘을 동시에 붙이고 나중에 고른다 | 비교가 자연스럽게 됩니다 | 이음매가 둘이 되어 스켈레톤이 검증하려던 성질이 흐려집니다. 22일 일정에서 두 경로를 함께 유지할 인원이 없습니다 |

## 결정

**A를 택합니다.** 이미지 생성 경로는 **당분간 외부 API(GPT 계열 이미지 API)만** 사용하고,
로컬 모델 채택 여부는 **검증 4순위(로컬 모델과 GPT 비교, IP-Adapter 효과 확인) 결과**를 보고
정합니다. 근거는 2026-08-11 회의 결정입니다 (회의록 A절 1번, 3번).

**이것은 로컬 모델 미채택 확정이 아니었습니다.** 판단 시점을 실험 뒤로 미룬 것이었고, 여기서
확정된 것은 "무엇을 쓸지"가 아니라 **"언제 정할지"**였습니다.

**2026-08-20 갱신: 그 판단이 내려졌고, 결과는 미채택입니다**
([회의록](../회의록/2026-08-20_검증4순위_로컬모델_미채택.md),
[미결정_대장.md](../기술문서/미결정_대장.md) A-5). 이 ADR 이 예약해 둔 재검토 시점이 발화한
것이며, **결정은 뒤집히지 않고 그대로 섭니다** - 외부 API 만 쓰는 것이 이제 잠정이 아니라
확정입니다. 위 문단을 지우지 않고 남기는 이유는, 이 ADR 을 쓸 때 **아직 정하지 않았다는 것**
자체가 결정의 일부였기 때문입니다.

로컬 모델을 다시 검토하려면 A-5 확정을 뒤집는 새 회의록이 먼저입니다. 이 ADR 이 그 문을
열어 두지 않습니다.

B를 택하지 않은 이유는 **선택의 근거가 아직 존재하지 않기 때문**입니다. 로컬 모델을 고르려면
VM에서 구동되는지(검증 8순위)와 한국어 대사를 그릴 수 있는지(검증 1순위)를 알아야 하는데, 둘 다
지금 진행 중입니다. 근거 없이 고른 뒤 뒤집으면 그때는 되돌릴 일정이 없습니다.

C를 택하지 않은 이유는 **이음매를 둘로 만들지 않기로 한 결정과 충돌**하기 때문입니다. 스켈레톤은
스텁을 우회해 옆에 새 경로를 만들지 않고 같은 이음매에서 갈아끼웁니다
([AGENTS.md](../../AGENTS.md) "현재 상태"). 생성 경로를 둘로 유지하면 폴백과 가드레일이 어느
쪽에 걸려 있는지가 곧 불분명해집니다.

## 결과

**생기는 제약**

- **API 키는 `infra/.env`에만 둡니다.** 이 저장소는 public이고, 커밋되는 순간 해결은 revert가
  아니라 폐기와 재발급입니다. 커밋 대상은 이름만 담은 `.env.example`입니다.
- **테스트에서 실제 호출을 하지 않습니다.** 비용이 들고 CI가 비결정적이 됩니다. 목으로 대체하되,
  가드레일을 목으로 바꾸는 것은 금지입니다 -- 그것은 테스트를 고치는 것이 아니라 보고 지표를
  무효로 만드는 것입니다.
- **비용이 사용량에 비례하므로 상한 논의가 따라옵니다.** 다만 상한은 실측 뒤에 정합니다
  (검증 6순위, 세션당 단가). 숫자 없이 상한부터 잡으면 실험 중에 다시 올리게 됩니다.
- **이미지 규격은 모델 제약을 그대로 받습니다.** 긴 변 3840px, 가로 세로 16의 배수, 총 픽셀
  약 8.29MP, 비율 3:1. 만화형 3456 x 2304는 이 제약 안에서 나온 값입니다 (기획서 10.2).

**쉬워지는 것**

- **GPU 1대 제약이 생성 경로에서 빠집니다.** VM의 GPU는 검증 4순위와 8순위 실험에만 쓰이므로,
  학습과 추론이 VRAM을 놓고 다투는 상황이 스켈레톤 기간에는 발생하지 않습니다.
- 라이선스 확인 범위가 서비스 약관 하나로 줄어듭니다. 모델 가중치의 상업적 이용 조항을
  원문으로 확인하는 작업은 로컬 모델을 채택할 때로 미뤄집니다.

**어려워지는 것**

- **생성 결과의 통제 수단이 프롬프트뿐입니다.** IP-Adapter처럼 가중치에 개입하는 방법을 쓸 수
  없어, 캐릭터와 화풍 일관성(검증 3순위)을 프롬프트 설계만으로 맞춰야 합니다.
- 외부 API 장애가 그대로 사용자에게 닿습니다. 시안 생성과 렌더에는 폴백이 없기 때문입니다
  ([ADR-0005](0005-열화_폴백은_자동화_생략으로_한정.md)).

**다루지 않는 것**

- **카피 생성 경로는 이 ADR의 범위가 아닙니다.** [착수_체크리스트.md](../공통_가이드/착수_체크리스트.md)가
  두 항목을 "같은 결정에 묶인다"고 적고 있지만, 2026-08-11 회의가 결정한 것은 **이미지 생성**
  경로입니다. 카피는 지연과 키 관리의 셈이 다르므로 별도로 정합니다.
- **파인튜닝 보류는 [ADR-0004](0004-파인튜닝_보류.md)로 따로 씁니다.** 이 결정에서 파생되지만
  되살릴 조건이 다르고, 한 파일에 결정 하나라는 규칙에 따릅니다.

**재검토 신호**

- ~~**검증 4순위 결과가 나올 때.**~~ **2026-08-20 에 발화하고 소진됐습니다.** 결과가 미채택이라
  어댑터 ADR 도 함께 소멸했습니다 ([회의록](../회의록/2026-08-20_검증4순위_로컬모델_미채택.md)).
  **남은 재검토 신호는 아래 둘뿐입니다** - 신호를 지우지 않고 소진으로 표시하는 이유는, 지우면
  다음 사람이 "이 결정은 재검토 없이 채택됐다" 로 읽기 때문입니다.
- 검증 6순위(세션당 단가)가 감당할 수 없는 숫자로 나올 때. 비용이 선택을 뒤집는 유일한 경로입니다.
- 외부 API의 약관이나 가격이 바뀌어 상업적 이용 또는 제출물 시연이 막힐 때.
