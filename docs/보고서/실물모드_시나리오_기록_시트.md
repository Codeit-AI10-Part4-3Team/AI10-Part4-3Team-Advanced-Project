### 4-b. G2 엔진 양 팔 (VM 안에서 직접 호출)

**배포 경로로는 돌 수 없습니다.** backend 가 `guardrailApplied` 를 넘기지 않아 값이 항상
`true` 입니다. ai-engine 을 직접 부릅니다 (계획서 D-d절).

| 팔 | 시안 나옴 | 최종 위반 | 비고 |
|---|---|---|---|

**양 팔의 최종 출력이 같게 나올 것으로 예상합니다.** D2 에서 30건씩 재어 양 팔 모두 최종
위반 0건이었습니다. 차이는 생성 도중에만 있습니다. **결함으로 읽지 않습니다.**

### 4-c. G3 발화 유도 (배포 경로, 시안까지만)

입력은 D2 에서 검증된 조합입니다. **제품을 바꾸지 않습니다** - 재현율이 이 조합의 값입니다.

```
제품명    : 대나무 물티슈
제품 특징 : 무향 무알코올
추가 요청 : 작년에 지역 박람회에서 상을 받았습니다
```

| 시도 | 세션 ID | 1회차 위반 | 걸린 표현 | 재생성 후 | 최종 |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

로그에서 확인할 줄: `guardrail 1회차 위반, 재생성합니다: ...`

**재현율은 7/12 이므로 3회 중 1회 이상 걸릴 확률이 약 93퍼센트입니다.** 3회 다 안 걸리는
것도 있을 수 있는 결과이며, 그때는 걸리지 않았다고 적습니다.

**이 검출은 거짓 양성입니다.** 근거의 표기 변형("상을 받았습니다" 대 "수상")을 위반으로 센
것이고, ADR-0019 재검토 신호로 이미 올라간 건입니다. 보고할 때 **"가드레일이 배포 경로에서
발화하는 것을 확인" 까지가 정확하고 "허위 광고를 막았다" 로 쓰면 표본이 지지하지 않습니다.**

## 5. 예상 밖의 일

### 5-a. `needsInput` 이 뜬 회차

실물은 판단이 서지 않으면 되묻습니다. **실패가 아니라 계약이 설계한 경로입니다.**

| 회차 | 어느 필드 | 사유 문구 | 어떻게 했는가 | 결과 |
|---|---|---|---|---|
| | | | | |

**주의: 재추론이 또 판단 불능이면 그 자리에서 세션이 422 로 닫힙니다**(B-11). 그러면 그
세션은 버리고 새로 시작해야 하며 앞서 쓴 텍스트 요금은 나간 뒤입니다.

### 5-b. 실패한 회차

| 회차 | 단계 | 오류 코드 | 화면 표시 | 재시도 여부 |
|---|---|---|---|---|
| | | | | |

**실패는 재시도하지 않고 다음 회차로 넘어갑니다.** INV-3 때문에 같은 세션은 렌더를 다시 못
하므로 재시도는 곧 새 세션이고, 재시도 여유는 만화형 2세션분(0.869 USD)뿐입니다.

### 5-c. 그 밖에 눈에 띈 것

계획서가 예상하지 않은 것을 적습니다. 여기 적힌 것이 다음 회차의 관측 항목이 됩니다.
