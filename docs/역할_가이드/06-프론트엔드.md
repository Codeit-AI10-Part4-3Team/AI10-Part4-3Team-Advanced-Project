## 한 줄 정의

이 역할이 없으면 **사용자가 쓸 수 있는 상태**가 되지 않습니다. curl로만 검증된 것은 서비스가 아닙니다.

## 소유 경로

`CODEOWNERS`와 **같은 경로**여야 합니다. 다르면 리뷰 자동 배정이 엉뚱한 사람에게 갑니다.

- `apps/frontend/`

## 책임

- 제품 정보 입력 + 레퍼런스 이미지 업로드 화면을 만든다
- **화풍 선택 화면(F2)을 만든다** — 후보는 **레퍼런스 이미지를 동반해** 제시합니다(2026-08-11 확정).
  후보 목록은 **03과 공동 소관**입니다([미결정_대장.md](../기술문서/미결정_대장.md) A-3이 정본,
  2026-08-12 PM 정리 — 경위는 [역할_일정/01](../역할_일정/01-기획_총괄.md)) — 목록은 아직
  차단 상태이므로 정해지기 전에는 화면 골격만 만듭니다
- 생성이 수십 초 걸린다는 사실을 UI로 다룬다 — 진행 상태 표시, 이탈 후 복귀
- 결과 갤러리와 다운로드를 제공한다
- **면책 고지 문구를 화면과 다운로드 안내에 붙인다** — 이미지 안이 아닙니다. 문구 확정은 PM
  소관이고(대장 A-7) 배치가 이 역할입니다
- `messageMode: degraded` 세션을 **일반 세션과 구분되게** 표시한다. 그 표기를 지우면 사용자는
  자동 추론이 동작한 줄 압니다 ([ADR-0005](../adr/0005-열화_폴백은_자동화_생략으로_한정.md))
- 스캐폴딩 전에 `apps/frontend/README.md`의 함정과 루트 `.gitignore`의 `lib/` 패턴을 먼저 읽는다

## 하지 않는 일 (경계)

책임보다 이 항목이 분쟁을 더 많이 막습니다.

- 모델 직접 호출 (backend 경유. 프론트에 키가 들어가면 public 저장소에서 즉시 유출입니다)
- 계약 변경 (02와 합의 후 `openapi.yaml`이 먼저)

## 산출물

| 산출물 | 위치 | 완료 판단 기준 |
|---|---|---|
| 입력 화면 | `apps/frontend/` | 텍스트 + 이미지 업로드가 잡 생성까지 관통 |
| 진행/결과 화면 | `apps/frontend/` | 탭을 닫았다 열어도 진행 중인 잡을 다시 찾을 수 있음 |
| 열화 표기 | `apps/frontend/` | `degraded` 세션이 시각적으로 구분됨 |
| 프론트 CI 활성화 | `.github/workflows/frontend-ci.yml` | 스캐폴딩 후 자동 활성 (non-required 유지) + **`if: hashFiles(...)` 가드와 `--if-present` 제거** — 남겨 두면 스크립트가 사라진 뒤에도 잡이 조용히 초록으로 통과합니다 |

## 인수인계 시 넘겨야 하는 것

이 역할이 빠졌을 때 다음 사람이 곧바로 이어받으려면 무엇이 문서로 남아 있어야 하는가.
**"머릿속에만 있는 것"을 여기에 적고, 그것을 없애는 것**이 이 항목의 목적입니다.

- 디자인 결정 중 코드에 드러나지 않는 것 (왜 이 흐름인가)
- 브라우저·기기별로 확인한 범위와 확인하지 않은 범위
