## 작성 규칙

- **"열심히 하겠다"는 대응이 아닙니다.** 대응은 코드·설정·절차 중 하나로 표현되어야 합니다.
- **감지 방법이 없는 리스크는 관리되지 않는 리스크**입니다. 무엇을 보고 발동을 알아차릴지 적으세요.
- 실현된 리스크는 지우지 말고 **결과와 함께** 남기세요. 다음 프로젝트의 자산이 됩니다.
