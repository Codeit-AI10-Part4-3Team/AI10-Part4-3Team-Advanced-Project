## 한 줄 정의

이 역할이 없으면 **로컬에서만 돌아가는 데모**로 끝납니다. 과제 요구사항의 절반(배포·운영)이 이 역할입니다.

## 소유 경로

`CODEOWNERS`와 **같은 경로**여야 합니다. 다르면 리뷰 자동 배정이 엉뚱한 사람에게 갑니다.

- `apps/backend/`
- `infra/`

## 책임

- 생성 잡의 수명주기(접수 → 진행 → 완료/실패)를 관리한다. **동기 HTTP로 붙들지 않는다**
- **로그인과 세션 소유 검사를 구현한다** (S0) - 고정 계정 둘로 아이디 조회 + 비밀번호 대조 +
  세션 쿠키 발급. 미인증은 401, 남의 세션 조회는 404(INV-9). 가입·탈퇴·비밀번호 변경은 계약만
  잡고 501입니다 ([ADR-0008](../adr/0008-로그인_수단과_스켈레톤_범위.md))
- **상태 저장소를 SQLite 파일로, 이미지 파일을 VM 로컬 디스크로 둔다.** 인메모리는 채택하지
  않습니다 - 재시작하면 진행 중 세션이 사라지고, 사용자에게는 "확정을 눌렀는데 결과가 없다"로
  보입니다 ([ADR-0010](../adr/0010-상태_저장소와_파일_보관_위치.md))
- **보존 기간을 지우는 코드를 만든다** - 업로드 사진 24시간, 브리프·시안·결과 이미지 7일, 로그
  30일. **일 1회 정리 배치**가 실제로 지우며, 기간과 주기는 설정값입니다
  ([세션_보관_정책.md](../기술문서/세션_보관_정책.md) 2절).
  문서에만 적혀 있으면 아무것도 지워지지 않고, 그 상태의 배포는 개인정보를 기간 없이 쌓는 것입니다
- `brief:fill` 장애만 열화로 처리한다. 자동 채움을 건너뛰고 `messageMode: degraded`로 진행하며
  세션은 `brief_filling`에 둔다. **시안 생성과 부분 교체는 폴백 없이 503 `UPSTREAM_UNAVAILABLE`,
  렌더는 잡 `status: failed` + `error.code`로 실패한다** - 렌더는 비동기 잡이라 HTTP 코드로
  실패하지 않습니다 ([ADR-0005](../adr/0005-열화_폴백은_자동화_생략으로_한정.md))
- **시안 생성이 실패하면 세션을 `brief_ready`로 되돌리고 브리프 잠금도 함께 푼다** - 잠긴 채
  실패로 남으면 사용자가 브리프를 고쳐 다시 시도할 방법이 없습니다
  ([ADR-0012](../adr/0012-시안_생성_실패_시_브리프_잠금_해제.md))
- GCP VM을 프로비저닝하고 compose 스택을 상시 기동 상태로 만든다
- 재부팅 후 자동 복구를 **실제로 재부팅해서** 확인한다
- 생성 지연, 실패율, `degraded` 비율을 사후 조회 가능하게 남긴다
- GPU 시간 분할 규칙(학습 vs 추론)을 합의하고 문서화한다
- **권한 경계를 확인하고 기록한다** — 커스텀 역할에 없는 권한은 우회하지 않고 학원에 요청하며,
  요청과 결과를 `infra/README.md`에 남긴다 ([ADR-0011](../adr/0011-배포_환경_스펙과_권한_경계.md))

## 하지 않는 일 (경계)

책임보다 이 항목이 분쟁을 더 많이 막습니다.

- 프롬프트 조립·모델 호출 (03 소관). backend는 GPU를 점유하지 않습니다
- 계약 변경 (02와 합의 후 `openapi.yaml`이 먼저)
- 시크릿 값을 저장소에 넣는 일 — `infra/.env.example`에는 **키 이름만**
- **비용 관리 (학원 소관)** — 결제 계정 권한이 없습니다. 예산 알림·지출 상한·크레딧 조회는
  이 역할의 일이 아닙니다. 2026-08-12 문의에서 학원은 **"감당 가능하니 신경 쓰지 않아도 된다"**고
  답했으므로 주기적 문의도 하지 않습니다. 다만 **리스크 9의 대응은 남습니다** — 시연·발표
  산출물을 보존 기간과 무관하게 미리 내려받아 두는 것은 크레딧뿐 아니라 VM 장애에도 걸리는
  대비입니다

## 산출물

| 산출물 | 위치 | 완료 판단 기준 |
|---|---|---|
| 비동기 잡 경로 | `apps/backend/src/` | 잡 접수 응답이 즉시 반환되고 상태 조회로 결과 수신 |
| 인증과 세션 복원 | `apps/backend/src/` | 미인증 401 · 남의 세션 404 · 프로세스 재시작 후 `GET /v1/sessions/{id}`로 복원 |
| 보존 기간 정리 배치 | `apps/backend/src/` + 배치 설정 | 만료된 사진·시안·결과가 실제로 사라지는 것을 확인 |
| 배포된 서비스 | GCP VM | 외부에서 접근 가능 + 재부팅 1회 실검증 통과 |
| 운영 관측 | `infra/` | 지연 p95, 실패율, `degraded` 비율을 사후에 조회 가능 |
| 권한 경계 기록 | `infra/README.md` | 커스텀 역할 포함 권한 전량 + 막힌 항목의 요청·결과가 표에 채워짐 |

## 인수인계 시 넘겨야 하는 것

이 역할이 빠졌을 때 다음 사람이 곧바로 이어받으려면 무엇이 문서로 남아 있어야 하는가.
**"머릿속에만 있는 것"을 여기에 적고, 그것을 없애는 것**이 이 항목의 목적입니다.

- VM에만 있는 설정 (방화벽 규칙, 서비스 계정 권한, 부팅 스크립트) — 저장소에 없는 것 전부
- 시크릿의 **보관 위치**(값이 아니라 위치)와 재발급 절차
- 장애 시 확인 순서 (무엇부터 보는가)
