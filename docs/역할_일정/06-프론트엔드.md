### 로그인 화면 완료와 다음 PR 범위 (2026-08-15)

**들어간 것**: React Router 도입, `/login` 화면, `GET /v1/me` 기반 세션 확인, 로그아웃,
보호된 경로(`RequireAuth`). 로컬에서 백엔드와 Vite 프록시를 함께 띄워 로그인 -> 조회 ->
로그아웃 -> 401 까지 확인했습니다.

**로그인을 먼저 붙인 이유는 선택이 아닙니다.** 계약의 보호 범위가 `/health` 와 `/v1/auth/*`
를 뺀 모든 `/v1` 경로입니다 (API_계약 6절). 세션 생성을 먼저 붙이면 첫 요청이 401 이고 그때
화면이 할 수 있는 일이 없습니다.

**CORS 는 다시 볼 필요가 없습니다.** #86 에서 Vite 프록시로 같은 출처를 만들어 두었고,
그것이 성립하는 조건은 `API_BASE_URL` 이 상대 경로로 남아 있는 것뿐입니다. 절대 URL 을 넣는
순간 프록시를 우회해 CORS 벽으로 되돌아갑니다.

**2번의 함정 셋**을 미리 적어 둡니다. 세션 생성은 실패가 아니라 **세 갈래**입니다 - 정상,

성공/실패로만 나누면 뒤의 둘이 오류 화면으로 가고, 열화는 설계된 동작이라 사용자가 아무 잘못도

경로를 미리 만들지 않았기 때문이며, 그 화면을 만드는 PR 에서 함께 넣습니다.

### S7 · S8 완료 (2026-08-19)

위 "다음 PR" 네 항목에 시안 · 확정 · 렌더 · 다운로드를 더해 한 번에 붙였습니다. 소관은 06

[00-overall.md](00-overall.md) 5절의 두 마일스톤이 여기 하나에 걸려 있었기 때문입니다.
**소관이 바뀐 것이 아니므로 이후 프론트 작업(F1, F2, F3, F5, F10, F13)은 그대로 06입니다.**

**들어간 것**: `/sessions/:sessionId` 경로, 실제 세션 목록, multipart 세션 생성, 브리프 표시,
시안 생성, 확정, `Retry-After`를 따르는 잡 폴링, 결과 이미지 표시와 다운로드. `mock-data.ts`는
지웠습니다.

**관통 확인(2026-08-19, 로컬 스택)**: 로그인 -> 세션 생성(multipart) -> `brief_ready` ->
시안 생성 -> 확정 -> 잡 폴링(`queued`에 `Retry-After: 3`, `done`에는 없음) -> 결과 WebP 내려받기
-> 세션 `completed`. 미인증 요청은 401, ai-engine을 끈 상태의 세션 생성은 201 +
`brief_filling` + `messageMode: degraded`.

**남겨 둔 것과 그 이유**를 숨기지 않고 적습니다.

| 무엇 | 지금 화면 | 왜 여기서 멈췄나 |
|---|---|---|
| 브리프 수정 | `filledBy`만 표시하고 고칠 수 없음 | 고치는 쪽이 F5(08-21)입니다. 표시만 먼저 둔 이유는, 자동으로 채워진 값을 자기가 쓴 것으로 오해한 채 시안까지 가면 그 시점에는 브리프가 잠겨 되돌릴 수 없기 때문입니다 (INV-7) |

| 만화형 시안 | 세션은 만들어지고 시안 생성 버튼이 없음 | 관통 경로는 단일 광고형 하나이고 만화형은 분기만 둔 스텁입니다 ([구현_범위.md](../공통_가이드/구현_범위.md) 1절). ⚠️ **버튼을 두면 안 되는 이유가 따로 있습니다** - ai-engine이 만화형을 503으로 거절하고 backend가 그것을 `UPSTREAM_UNAVAILABLE`로 옮기므로, 화면에는 "엔진에 연결하지 못했습니다"로 도착합니다. 없는 장애를 있다고 말하는 화면이 됩니다 |

### 08-26 만화형 개방이 무엇에 막혀 있는지 정리했습니다 (송기하)

**코드는 반나절이고, 막고 있는 것은 코드가 아닙니다.** 게이트 한 곳(`DraftPanel.tsx` 의
`outputType === "comic"` 분기)을 걷는 것이 전부이고 화면 쪽 `panels` 렌더는 이미 있습니다
(`DraftView.tsx`). 그런데 걷어도 확인할 방법이 없고, 확인 없이 걷으면 사용자가 볼 것이
"엔진에 연결하지 못했습니다" 입니다.

로컬 스택에서 만화형을 실제로 만들어 지금 무엇이 보이는지 확인했습니다.

| | 단일 광고형 | 만화형 |
|---|---|---|
| 세션 생성 | 됩니다 | **됩니다** |
| 시안 만들기 | 됩니다 (스텁 카피) | **버튼이 없습니다** |
| 오류 표시 | 없음 | **없음** - 오류가 아니라 안내 문구입니다 |

⚠️ **만화형은 "에러가 나는" 것이 아니라 "진행할 수 없는" 상태입니다.** 세션은 만들어지고
브리프도 채워지는데 거기서 길이 끊깁니다. 오류로 보고되지 않도록 일부러 그렇게 두었습니다.
