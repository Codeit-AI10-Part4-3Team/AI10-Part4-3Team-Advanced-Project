# training/data — 데이터셋 배치 규약

이 폴더의 **실제 데이터는 커밋되지 않습니다**(`.gitignore`). 추적되는 것은 이 README뿐입니다.
데이터가 없어도 무엇을 어디에 두어야 하는지 알 수 있게 하는 것이 이 문서의 목적입니다.

## 레이아웃

```
training/data/
  <dataset-id>/          예: brand-v1
    images/              원본 이미지 (파일명 = 안정적인 ID, 공백·한글 금지)
    captions.jsonl       {"file": "images/0001.jpg", "text": "..."} 한 줄에 하나
    LICENSE.md           이 데이터셋의 권리 근거 (아래 표를 이 파일에도 복사)
```

`<dataset-id>`는 **한 번 붙이면 바꾸지 않습니다.** config와 학습 로그가 이 문자열로 서로를
가리키므로, 내용이 바뀌면 이름을 바꾸는 게 아니라 **새 버전을 만듭니다**(`brand-v2`).

## 데이터 출처 대장 (채워야 하는 표)

학습을 돌리기 전에 이 표가 채워져 있어야 합니다.

## 주의

- 사람 얼굴·상표·타인의 저작물이 포함된 이미지는 **범위 근거를 개별로** 적으세요.
  "인터넷에서 수집"은 근거가 아닙니다.
- 캡션에 개인정보(이름·연락처·주소)가 섞여 들어가는 사고가 잦습니다. `prepare` 단계에서
  걸러야 하며, 걸러지지 않은 채 학습되면 모델 가중치에서 되돌릴 수 없습니다.
- 원본은 이 폴더가 **유일한 사본이 아니어야** 합니다. 여기는 gitignore 대상이라 실수로
  지우면 복구 수단이 없습니다.
