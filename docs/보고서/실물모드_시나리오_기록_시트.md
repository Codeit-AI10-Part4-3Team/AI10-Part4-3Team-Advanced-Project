# 실물 모드 시나리오 기록 시트

빈 양식입니다. **왜 이렇게 도는지는 여기 없습니다** -
[계획서](실물모드_시나리오_테스트_계획서.md)에 있습니다.

| 수행 | | 실행 일자 | | 전체 시작 | | 전체 종료 | |
|---|---|---|---|---|---|---|---|

> 예시: 수행 `임동규` / 실행 일자 `2026-08-29` / 전체 시작 `14:05` / 전체 종료 `15:40`
>
> **기울임으로 된 `예시` 행은 지우고 쓰십시오.**

**회차마다 다섯 칸이고 그중 셋은 고르기만 하면 됩니다.** 시간은 적지 않습니다 (서버가 로그에
남깁니다). 한 번에 한 세션씩 돕니다.

## 0. 실행 전 (요금 0. 하나라도 어긋나면 중단)

**VM 에는 파이썬 환경이 없습니다.** 전부 컨테이너 안에서 돕니다. 아래를 그대로 붙여넣으세요.

```bash
cd /srv/adcraft/app
C="docker compose -f infra/docker-compose.yml"

# 0-1 가드레일 검출기. eval 은 이미지에 없어 먼저 넣습니다
$C cp apps/ai-engine/eval ai-engine:/tmp/eval
$C exec ai-engine python /tmp/eval/run_guardrail_detector.py

# 0-2 생성 모드
$C logs ai-engine | grep "generation seams"

# 0-3 키 길이
$C exec ai-engine sh -c 'echo keylen=${#ADGEN_MODEL_API_KEY}'

# 0-4 키가 모델에 닿는가
$C exec ai-engine python -c "import os;from openai import OpenAI;print(len(OpenAI(api_key=os.environ['ADGEN_MODEL_API_KEY']).models.list().data))"

# 0-5 화풍 카탈로그. backend 입니다
$C exec backend python -c "import json,os;print(len(json.loads(os.environ['ADGEN_ART_STYLES'])))"

# 0-6 품질 override
$C exec ai-engine sh -c 'echo "override=[${ADGEN_IMAGE_QUALITY_OVERRIDE}]"'

# 0-7 화풍 예시 파일
$C exec backend sh -c 'ls /data/art-styles | wc -l'
```

| | 확인 | 기대 | 실제 |
|---|---|---|---|
| [ ] | 0-1 검출기 | `10/10`, `6/6` | |
| [ ] | 0-2 생성 모드 | `'model' mode` | |
| [ ] | 0-3 키 길이 | 0 아님 | |
| [ ] | 0-4 모델 접근 | 숫자가 나옴 | |
| [ ] | 0-5 화풍 카탈로그 | `8` | |
| [ ] | 0-6 품질 override | `override=[]` | |
| [ ] | 0-7 예시 파일 | `8` | |
| [ ] | 입력 화면의 화풍 격자 | 8칸 | |

0-5 는 **`backend`** 입니다 (ai-engine 에 물으면 `KeyError`). 0-6 이 비어 있지 않으면 만화형이
다른 티어로 돕니다. 둘 다 멈출 사유입니다.
